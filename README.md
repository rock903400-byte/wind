## 常見問題 (FAQ)

**你主要接哪些類型的案子？**
以「需要一次就到位的成品網站／工具」為主，從品牌形象網站、線上工具、電商 POS、LINE/AI 整合到金融試算都有實際成品，可參考上方作品一覽。

**團隊還是個人？**
目前為個人開發者，配合 AI Agent 加速落地，做到「報價→成品」都可線上演示。

**怎麼聯繫你？**
請透過 GitHub Profile 上的聯絡資訊，或直接在本專案 Issues 留下您的需求（含預算與時程），我會主動回覆。

**我的產業你的作品完全沒有，可以接嗎？**
可以——跨產業正是特色，我會先用你的流程與素材快速熟悉領域，再交付可上線的作品。
